## 📁 Repository Overview

- **`frontend/`**: Main React 19 + Vite + Tailwind CSS + WebGL 3D Ferrofluid visualizer application.
- **`music-streaming-app/`**: Full-stack backend module (Node.js + Express.js + MySQL streaming API).
- **`aura-landing/`**: Standalone React marketing landing page.
- **`music-assets/`**: Python asset generator (`generate_assets.py`), metadata catalog (`songs.json`), songs, artwork, and lyrics.

## 🚀 Quickstart

### 1. Backend Server
```bash
cd music-streaming-app/backend
npm install
npm run dev
```

### 2. Frontend Web App
```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser!
