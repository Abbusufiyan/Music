## ⚡ Frontend Quick Summary (`/frontend`)

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Framer Motion
- **3D Visualizer**: OGL WebGL Ferrofluid Visualizer ([Ferrofluid.jsx](file:///home/omr/Desktop/music-app/frontend/src/components/Ferrofluid.jsx))
- **State Management**: React Context ([AppContext.jsx](file:///home/omr/Desktop/music-app/frontend/src/context/AppContext.jsx))
- **API Integration**: Axios client ([apiClient.js](file:///home/omr/Desktop/music-app/frontend/src/api/apiClient.js)) + backend services

### Running Locally
```bash
npm install
npm run dev
```
App will launch on `http://localhost:5173`.
